# Redirects

GitHub Pages has no server-side redirects; these become meta-refresh pages
with a canonical link (or real 301s if hosting moves to Cloudflare/Netlify).

| From | To | Why |
|---|---|---|
| `/new-page` | `/publications` | Squarespace default slug |
| `/new-page-1` | `/` | Duplicate home page |
| `/ux-design` | `/` | Near-empty page |
| `/foldersux` | `/` | Squarespace nav folder |
| `/missioncontrol-1` | `/mxtract` or `/` | Depends on the mXtract decision |

All other slugs stay the same: `/depmap`, `/gutsee`, `/missioncontrol`,
`/webster`, `/metmap`, `/timecube`, `/visual-design`, `/about`.
